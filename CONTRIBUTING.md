# Contributing

Use the local setup in README.md, then run `php artisan test` before submitting a change.

Keep pull requests focused on one issue. Include the problem, the behavior after the change, and the checks you ran. For interface changes, include desktop and mobile screenshots in both themes.

Keep UI strings in the language files and update all four supported languages. Keep dependencies in composer.json and composer.lock, not in vendor. Do not commit credentials, local configuration, databases, or backups.

Report suspected security issues privately using SECURITY.md rather than opening a public issue with exploit details.

Contact the maintainer before submitting contributions. Any contribution must include written permission for its use and distribution under the project license.
