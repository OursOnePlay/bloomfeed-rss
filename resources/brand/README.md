# BloomFeed logo

The logo is drawn in `logo.html` using HTML text and CSS shapes. It uses no external images or fonts.

PNG exports are stored in `public/images/logo.png`, `logo-dark.png`, and `icon.png`. They have transparent backgrounds. The wordmark exports use a 1000 by 240 CSS-pixel viewport at 2x resolution. The icon uses 240 by 240 at 2x.

For a dark export, set the body class to `dark`. For the icon, use the `icon` class. Render in Chromium with a transparent default background, then capture the viewport.
